# zhangyunfan23.github.io

Personal website of **Zhang Yunfan, Ph.D.** — Research Scientist at the Alibaba-NTU Global e-Sustainability CorpLab (ANGEL), working on LLMs and 3D computer vision.

🌐 Live site: <https://zhangyunfan.tech>

## About

This site hosts my bio, news, publications, and CV. Topics I work on include:

- Domain-specific LLMs for clinical applications (GraphRAG, KAG, multi-turn diagnostic dialogue)
- Inference efficiency (vLLM, FlashAttention, SDPA)
- 3D generative pipelines and point cloud generation

## Built with

Forked from the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme. Refer to the upstream repository for theme documentation, customization guides, and deployment options.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open <http://localhost:4000>.
